# Games for Couple

Read [MEMORY.md](MEMORY.md) first. It has the current status, the decisions made so far and what's next. **Update it at the end of every session**: refresh the status table and add a dated Log entry on top.

- Game specs live in `docs/`. Finish My Sentence: [docs/finish-my-sentence-spec.md](docs/finish-my-sentence-spec.md).
- Run `npm test` and `npm run typecheck` before calling work done.
- Keep each game isolated in its own folders (`client/src/games/<id>`, `server/src/games/<id>`, `shared/src/<id>`), and register new games in `shared/src/games.ts`.
